# Proyecto Intermodular ASIR – KINU

Proyecto final del ciclo de ASIR (curso 2026-2027).

## De qué va

KINU es una tienda online ficticia de ropa streetwear. Su web está montada sin ninguna protección, así que el proyecto consiste en:

1. Montar su infraestructura en máquinas virtuales.
2. Atacarla tal como está.
3. Protegerla (cortafuegos, bastionado, WAF y monitorización).
4. Volver a atacarla y comparar los resultados.

## Herramientas

VMware · OPNsense · Ubuntu Server · Apache + PHP + MariaDB · ModSecurity · Wazuh · Kali Linux
